## 素材操作、封面与参考选择修复交接

使用方法：My Assets 卡片的操作自动分行，Image Studio 结果随实际内容区宽度排布。视频保存到素材后补首帧封面；旧无封面素材滚入可见区域时补齐。封面为独立 videoCover 图片记录，经现有 storageKey/云上传链路持久化，不覆盖视频、原封面或用户后续修改；离线失败保留原视频，View 可播放。素材包同时包含本地封面。

画布打开节点输入面板，点击 References 的加号，按提示点击其他有内容的兼容节点；可连续添加，Done 或 Esc 返回。从 My Assets 选择会新建资源节点并连接到目标，仍使用原引用关系、断开和撤销机制。只显示兼容类型，平台 ali-image 为文字参考，参考图片编辑须选择支持编辑的其他模型；平台视频依据服务端目录能力筛选。

本轮只在独立本地验收源使用可丢弃素材，没有生成调用或生产数据写入。桌面覆盖 Agent 展开，手机 390px 覆盖图片结果；素材历史视频补封面并刷新可见，画布素材插入/连线/断开/重新选择/Esc 已验证。自动化覆盖封面持久化、请求去重、原视频保留、并发用户修改/删除保护、取消读取清理，以及模型类型与分组筛选。窄屏原画布侧栏和浮层会挤占空间，本轮不扩展重构，仍需人工验收。

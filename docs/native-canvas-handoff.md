# 海外原生画布前端交接

本轮恢复完整原版能力，并接入个人提示词和云收藏。开发在 `dev`，仅本地提交，不推送、不部署；不触发真实付费生成，保留独立版和国内版行为及历史数据。

- 完整页面、导航、配置、插件及 Agent 入口恢复。平台与自配请求按渠道分流，平台视频使用账号余额，自配供应商直接结算。
- bootstrap 保留用户自配渠道、密钥和所选模型。平台渠道不能编辑密钥，账号配置与本地业务存储隔离。
- 个人提示词支持新增、编辑、删除、刷新，整合原列表与画布提示词选择器。
- 收藏采用 `/library` 的原生文档与 revision CRUD；不再从媒体文件列表自动重新加入已删除收藏。失败保留当前与前次恢复副本，恢复成功后才清理备份。
- 独立 Video 页面接入平台估价确认、稳定请求键和任务查询，自配视频继续原流程。
- 原生节点、连线、分组、撤销重做、导入导出等结构继续沿用；旧项目仅复制导入，不改写历史。

接口与真实缺口见 [接入契约](native-canvas-next-interfaces.md)，启动、运维和存储说明见 [开发文档](content/docs/development/overseas-workbench.mdx)，本地测试与截图记录见 [验收记录](native-canvas-acceptance.md)。

平台当前没有确认图片/文本/音频模型及价格，相关平台适配只是未启用草案；可用原自配渠道完成这些操作。插件和 Agent 是用户自配能力，没有完成平台托管接入。文档保存成功不等于外部媒体已备份。

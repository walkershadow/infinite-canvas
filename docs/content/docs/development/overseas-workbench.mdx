# 海外 Workbench 原生画布

海外模式复用原版完整界面与交互：首页、画布、图片、视频、提示词、素材、配置、插件和 Agent。平台视频通过 Workbench 的账号余额计费；用户自配渠道由前端直连供应商并由供应商结算。默认独立模式不变，画布及素材主要保存在浏览器本地，API Key 同样保存在浏览器本地。

当前仅本地开发，未部署到海外生产、独立生产画布或国内站。

## 启动与路由

在 `web/` 执行：

```sh
VITE_APP_MODE=overseas bun run dev --host 127.0.0.1 --port 3200 --strictPort
```

`WORKBENCH_DEV_ORIGIN` 默认 `http://localhost:3100`。Workbench 端配置 `NATIVE_CANVAS_DEV_ORIGIN=http://localhost:3200` 后，从 `http://localhost:3100/canvas/` 使用本地登录会话联调。不要混用 localhost 与 127.0.0.1，避免 cookie 不匹配。不要复制生产 cookie 或覆盖已有环境配置；示例在 `web/overseas.env.example`。

海外资源 base 和路由 basename 均为 `/canvas/`（路由配置不含结尾斜杠）。原内部路径不变，因此项目列表为 `/canvas/canvas`，项目为 `/canvas/canvas/:id`；图片、视频、提示词、素材和配置分别为 `/canvas/image`、`/canvas/video`、`/canvas/prompts`、`/canvas/assets`、`/canvas/config`。旧 `/canvas/:id` 项目别名保留。Workbench 根页通过整页链接返回。

模式由构建环境决定，不通过 URL 参数或项目内容切换。默认未设置 `VITE_APP_MODE` 即独立模式。

## 渠道与账户

入口先完成 `/api/canvas/bootstrap`，再加载会初始化存储的应用模块。未登录不能加载旧账号的数据；后续 JSON 请求附带 `X-Canvas-Account`，账号变化拒绝继续操作并要求重载。写请求的 cookie、账号 header、Origin 由服务端校验。

平台渠道 `workbench` 由 bootstrap 管理，不要求填写 API Key，也不可编辑或删除。新用户默认平台视频模型；初始化不覆盖已有自配渠道及选择。用户自配 endpoint、模型、密钥与脚本继续原请求流程，费用不计入 Workbench 余额。密钥与偏好只保存在账号隔离的本地配置，不进入云项目、个人提示词或收藏文档。

原插件和 Agent 入口及手动连接可用；这些是用户自行配置的功能，并非平台托管服务。平台没有确认图片、文本、音频模型与价格，当前须使用自配渠道。预留的平台 AI 适配需完善计费、幂等、响应语义并通过验收后才能启用。

## 云数据与媒体

项目保留完整原生 schemaVersion/document.id，适配层另存服务端 envelope id/revision。提交前保存项目；视频 requestKey 与目标节点绑定，重试复用，恢复任务按 createdAt 选择同节点最新记录。独立视频页使用 `/video/generate` 与 `/video/tasks/:id`，不创建可见空画布。

个人提示词使用 `/prompts` CRUD，收藏使用 `/library` CRUD，更新/删除携带 revision。收藏保持文本、图片、视频、标签、备注、标题等原字段。文件上传用 `/assets`，收藏删除不等于媒体文件删除，也不会从媒体列表自动复活。

有 storageKey 的本地原文件在云文档保存时上传平台，云文档中替换成同域持久媒体 URL。无法下载而只留下外部链接的媒体不保证持久性；平台任务播放 URL 也不等于已复制云素材。界面明确显示文档保存状态及媒体说明。供应商 CORS、链接过期、跨设备读取和大文件均需实际验收。

账号级 localforage 数据库包含恢复副本、媒体、收藏、插件及生成历史；偏好与 Agent 连接参数也使用账号前缀。独立版数据库与键名保留，海外模式不读取或迁移独立版历史。个人提示词和收藏跨设备依赖云端，偏好与生成历史仍属于本地数据。

## 故障处理

- 项目或收藏出现 409 时停止自动覆盖，保留本地恢复文件。先导出，确认云端状态，再选择恢复为新项目/收藏；不要直接删 IndexedDB。
- 收藏首次加载失败时先保留本地状态，不在未知云版本上执行写入；重试先重新加载云数据。
- 前次收藏恢复副本未处理时禁止自动写入覆盖；损坏副本保留原始字节供导出。
- 未保存恢复数据可能引用本地原媒体，海外自动媒体清理暂不运行，避免破坏恢复能力。
- 文档同步失败不阻止用户打开其他功能页面；错误会显示在顶部，不把未保存状态当作成功。
- 不自动重试收费创建、不更换不确定结果的请求键；余额与实际成本以服务端为准。

## 本地检查与发布边界

在 `web/` 执行以下命令，分别生成到临时目录，不覆盖独立站输出：

```sh
bunx tsc --noEmit
bun test
VITE_APP_MODE=overseas bun run build --outDir /private/tmp/infinite-canvas-overseas-check
bun run build --outDir /private/tmp/infinite-canvas-standalone-check
```

集成测试在独立进程执行，防止 module mock 污染原版模型选择测试。浏览器验收使用独立测试页，不关闭用户原有标签。测试无付费调用；真实生成、扣费退款、跨设备媒体和生产代理需另外验收。Docker 静态资源路径仍是待办，不能宣称已验证生产部署。
